# Data availability

The empirical application uses a dataset of 860 observations of French wines
sold in Belgian supermarkets. It contains prices, vintages, regions, wine
types, ratings, labels, sensory characteristics, and physicochemical variables.

The original `wine.xlsx` file is not redistributed in this public repository
because its redistribution rights have not been established. To reproduce the
empirical section, place an authorized copy at `data/wine.xlsx`.

All Monte Carlo simulations in `research_notebook.ipynb` generate their data
programmatically and do not require the wine dataset.
